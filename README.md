# Cybersécurité Sonatel Académie ODC

Plateforme d'apprentissage en cybersécurité (site statique, un seul fichier `index.html`).

- **Module 1 — Réponse à incident** : les 22 fiches IRM du CERT aDvens (version française), https://github.com/cert-advens/IRM, licence CC BY 3.0, texte extrait des PDF et remis en forme.
- **Module 2 — Forensique Windows** : synthèse rédigée pour la plateforme sur les artefacts Windows (thème du poster SANS FOR500, dont le texte n'est pas reproduit).
